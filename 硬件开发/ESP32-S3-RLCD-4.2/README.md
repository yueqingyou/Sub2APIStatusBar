# ESP32-S3-RLCD-4.2 监控屏

本目录保存 TokenRouter Monitor 独立硬件监控屏的固件、公开硬件文档和验收记录。

当前源码候选为 `0.8.4`：在 `0.7.0` 的低频监控和独立 BLE 升级链路上，加入由板载 `GPIO4` 三倍分压真实采集的电量估算。电量百分比固定显示在四页右上角，设备页另行显示实测电压；Mac 设置提供独立的 5 分钟至 1 天采样周期，默认 15 分钟，并通过监控协议 5 下发。每次采样使用校准后的一次性 ADC 小批量平均值并立即释放资源，设置变化或显示值不变时不会重绘电子纸。四页正文在不改变页头和电量坐标的前提下整体下移，Overview、Tasks 和 Quota 只重新分配既有快照信息以铺开 400×300 画布，保留原有主次字号，没有加入实时并发、活动任务、倒计时或装饰性卡片。

两个独立 ESP-IDF 5.5.2 目录生成了逐字节一致的 bootloader、分区表、OTA 元数据和 643,504 字节应用镜像，应用 SHA-256 为 `e5d230dd852a3ef88f8a12ce709f76a78a1406dd24f3d98d8eb31cd9ee34fa33`，App 内置资源已完成同值校验。实物先从 `0.7.0` 经已绑定加密 BLE 升级到电量中间验收版 `0.8.1`，再依次升级到全画布布局中间版 `0.8.2`、保留原有主次字号的 `0.8.3` 和正文进一步下移的 `0.8.4`，四次都没有执行 USB Flash 写入。`0.8.4` 已从 OTA 0 启动、恢复原绑定、完成协议 5 握手、确认运行镜像并收到 Mac 保存的 30 分钟电量周期；启动读数为 `3.88V / 81%`。实机目视确认电量在四页固定显示，正文下移后上下留白更均衡，既有内容没有裁切或重叠。电压尚未通过万用表对照校准，整板功耗和续航也尚未测量，因此不得据此宣称电量精度或续航结果。

- `HARDWARE_MONITOR_DESIGN_ZH.md`：整体方案、硬件决定和实施进度；
- `firmware/`：正式 ESP-IDF 固件；
- 设备专属 Flash 备份、构建缓存和临时日志放入 `tmp/yyyy.mm.dd/`，不得提交。

本机 ESP32 工具和依赖只使用 MacPorts。固件使用 ESP-IDF 5.5.2；屏幕只在切页、链路状态或实际显示值变化时刷新，相同数据不会重复重绘。独立离线检查关闭时，设备仍会按当前页同步周期延迟判定 Mac 离线。绑定使用 LE Secure Connections Just Works，有加密但没有 MITM 认证；实体按键和限时窗口是首次授权边界。下一阶段是万用表电压校准、运行与深度休眠功耗、RTC 定时休眠和外壳验证。

ST7305 显示适配层基于 Waveshare 的 Apache-2.0 示例修改；原始版权、许可证副本和修改声明保存在 `firmware/components/u8g2_st7305/`。
