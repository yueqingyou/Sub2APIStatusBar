# TokenRouter Monitor 固件

本目录是 ESP32-S3-RLCD-4.2 的正式 ESP-IDF 固件。当前源码候选为 `0.9.4`，包含概览、任务、配额和设备四页。电池由 `GPIO4` 上的三倍分压接入 ADC1；每次丢弃 4 个预热值、平均 16 个一次性采样，使用 ESP32-S3 曲线校准换算电压后立即释放 ADC。电量百分比固定在四个普通页面的右上角，设备页另行显示实测电压，并保留一个大号 Mac 状态以及 BLE、数据状态和固件版本。采样周期由 Mac 设置独立配置为 5 分钟至 1 天，默认 15 分钟；固件启动先绘制首帧，再采样电量，ADC 初始化失败只显示 `BAT N/A` 而不会阻断显示或 BLE。百分比按官方 `2.5V–4.2V` 线性口径估算，不表示燃料计精度，也不推断充电状态或剩余时长；只有显示到两位小数的电压或整数百分比变化时才重绘，单独改变采样周期不会重绘。

Overview 将费用、请求/Token 和三项健康状态分成三层铺开画布；Tasks 保留近期总数与 Done、Error、Stale 三项结果并把分类结果下移；QUOTA 继续显示五小时和七天剩余容量百分比，以及各窗口最早下一次重置的剩余时长快照，固定保留 `D`、`H`、`M` 三段。三页只纵向重排已有低频快照，并保留原有主次字号；不显示或接收 Normal Account、实时并发、活动任务、运行数或等待数，也不加入会自行倒计时的字段。普通页面不常驻显示页码、按键教程和重复链路状态。

`0.9.0` 把 ST7305 切到 `1 Hz` LPM，并启用 ESP32-S3 `40–160 MHz` 动态降频、自动 Light-sleep 与 NimBLE modem sleep；BLE 低功耗时钟使用主晶振，不依赖外部 32 kHz 硬件。主循环由固定 `20 ms` 轮询改为 GPIO/BLE 事件唤醒和最长 1 秒的空闲等待，未使用的 SHTC3 进入休眠，PCF85063 `CLKOUT` 关闭。已绑定设备断线后先以 `20 ms` 间隔快速广播 30 秒，再固定为 `1022.5 ms`；60 秒首次配对窗口始终快速广播。短按板载 `KEY` 仍依次切页，长按 1.5 秒仍开启配对窗口。

监控协议 6 新增独立休眠计划包。macOS App 按北京时间下发当前时钟、启用状态和起止分钟，默认 `23:30–07:30`，并每小时低频校时；设备只在至少成功接收一次 Mac 时间后持久认可 RTC。进入计划窗口时，显示控制器按 ST7305 要求从 LPM 切回 HPM，再执行 `SLPIN`，随后 ESP32-S3 进入 Deep-sleep；屏幕、BLE 数据同步和固件升级均离线。PCF85063 每日告警和 ESP32 定时器共同提供计划结束唤醒，实体 `KEY` 可提前唤醒并只跳过当前窗口。休眠期间的 Mac 设置修改会在设备下次连接后生效；固件升级进行中、首次配对窗口打开或 OTA 运行镜像尚未确认时不会进入休眠。

两个各自从 `sdkconfig.defaults` 生成新 `sdkconfig` 的 ESP-IDF 5.5.2 构建目录，生成了逐字节一致的配置、bootloader、分区表、OTA 元数据和 693,696 字节 `0.9.4` 应用镜像；应用 SHA-256 为 `9ac18db3ac2f6978bb22fcd2623b839c29d9f0b5e51af28eaa7c5c80b36e283a`。App 内置资源清单已通过型号、版本、监控协议 6、升级协议 1、大小和 SHA-256 校验。隔离候选 App 经原有加密绑定把实物从 `0.9.3` 升级到 `0.9.4`，完成 `100%` 传输、设备断线重启、原绑定加密回连和 `0.9.4` 目标版本回读。

USB 串口与 JTAG 确认 PCF85063 未置位告警或定时标志，而普通 GPIO 输入在引脚切换到 RTC IO 域后给出了错误判断。`0.9.4` 把入睡前稳定性检查和最后瞬时告警检查改为 `rtc_gpio_get_level()`，不改变 RTC、备用定时器和 `KEY` 唤醒政策。北京时间 `19:05–19:08` 的临时计划中，设备只断开一次，随后 133.118 秒内不可发现，133.304 秒后连接，回报 `rtcInterrupt`、恢复协议 6 加密绑定并回读 `0.9.4`。默认 `23:30–07:30` 已恢复并重新下发。实体 `KEY` 提前唤醒、备用定时器单独唤醒、完整默认过夜窗口、两阶段广播的精确射频时序、屏幕 `1 Hz` 模式的物理确认和整板功耗仍待实测。

上一实机屏幕与电量基线 `0.8.4` 已通过原有加密绑定写入实物 OTA 0，设备完成整包校验、重启、首帧、运行镜像确认、自动回连和目标版本握手；实机目视确认四页电量位置固定，正文下移后上下留白更均衡，既有内容没有裁切或重叠。`0.9.4` 已完成最终镜像 BLE 升级、重启回连、真实不可发现休眠和 RTC 唤醒；电压仍未完成万用表校准，运行、广播、同步和深度休眠的整板功耗仍未测量。

未绑定且配对窗口关闭时，设备不广播项目服务。长按允许一台 Mac 使用 LE Secure Connections Just Works 建立加密绑定；已有绑定不会被普通长按单方删除，绑定保存在 NVS，重启后可自动恢复。由于开发板没有密码或数字确认输入，该模式不提供 MITM 认证；实体长按和 60 秒窗口是授权边界。

安全链路的监控协议版本为 6。握手只确认监控数据兼容性；随后 Mac 先同步北京时间休眠计划，再根据设备当前页发送低频脱敏快照，并在每个页面包和心跳的公共前缀中携带独立电量采样周期。固件只接受 300 至 86,400 秒范围，间隔变化不增加页面数据修订。Mac 不发送实时并发、活动任务、运行数或等待数。QUOTA 的重置剩余时长由 Mac 在完整同步时计算，固件不会在同步之间自行倒计时或为此定时重绘。独立轻量心跳只更新 Mac、网络和 TokenRouter 在线状态；关闭独立检查时，离线超时自动跟随当前页的完整同步周期。设备不会接收凭据、账号身份或原始 API 响应。相同数据仍会更新在线计时，但不会触发整屏重绘。

固件升级协议独立固定为版本 1，因此新版 App 即使遇到旧监控协议也能进入仅升级模式。升级只接受已绑定且已加密的 BLE 连接；Mac 发送目标版本、镜像大小和完整文件 SHA-256，固件把数据写入非运行 OTA 分区，并在结束时校验接收长度、SHA-256、ESP 镜像结构、项目名和目标版本。升级界面只显示阶段、进度和保持供电提示。校验通过后切换启动分区并重启，新固件完成屏幕与 BLE 初始化后才取消回滚；首次启动失败时 bootloader 回到上一分区。

GATT 服务表使用独立持久化版本。新增或移除服务和特征时，设备通过标准 Service Changed 指示使已绑定 Mac 的缓存失效，并在收到确认后记录新版本；Mac 收到服务失效回调后自动重新发现。升级服务表不要求删除绑定、重新配对或再次 USB 初始化。

从旧单应用分区迁移时只需一次 USB 初始化：写入 `0x0000` bootloader、`0x8000` 分区表、`0x10000` factory 应用和 `0x610000` OTA 元数据，不执行全片擦除，也不覆盖从 `0x9000` 开始的 NVS，因此保留蓝牙绑定。用于验证真实蓝牙升级的 USB 引导镜像版本为 `0.6.9`；当前 App 内置候选资源使用 `0.9.4`，不得与引导镜像混用。完成这次初始化后，日常固件升级只通过 macOS App 的 BLE 操作进行。

固件固定使用 ESP-IDF 5.5.2，并通过 ESP Component Registry 固定使用 `nixy4/u8g2` 0.1.4。ST7305 初始化参数和屏幕引脚基于 Waveshare 官方示例；当前分区布局使用 2 MiB factory、2 MiB OTA 0、2 MiB OTA 1 和独立 OTA 元数据，同时保留既有 NVS。

`components/u8g2_st7305/` 基于 Waveshare 的 Apache-2.0 示例修改，目录内保留原始版权、许可证副本和修改声明。通过 ESP Component Registry 获取的 U8g2 仍适用其自身许可证。

构建前先加载基于 MacPorts Python 3.12 的 ESP-IDF 5.5.2 环境，然后在本目录执行 `idf.py build`。构建目录、自动下载的组件和本机 `sdkconfig` 不提交。正式候选必须为两个独立构建目录分别指定尚不存在的新 `SDKCONFIG`，让 `sdkconfig.defaults` 生成完整配置；不得复用或复制开发目录的已生成 `sdkconfig`。必须先比较两份 `sdkconfig` 并确认电源管理和 Tickless Idle 实际启用，再比较 bootloader、分区表、OTA 元数据和应用镜像。组件版本由 `idf_component.yml` 和 `dependencies.lock` 共同固定，顶层 CMake 会拒绝带空格编号的组件冲突副本。正式 `0.9.4` 构建完成后，从仓库根目录运行 `./scripts/update-hardware-firmware-resource.sh <构建目录>` 更新 App 资源，再运行 `./scripts/verify-hardware-firmware.sh` 复核清单与 SHA-256。
