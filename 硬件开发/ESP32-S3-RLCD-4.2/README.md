# ESP32-S3-RLCD-4.2 监控屏

本目录保存 TokenRouter Monitor 独立硬件监控屏的固件、公开硬件文档和验收记录。

当前源码候选为 `0.7.0`：在五小时和七天剩余容量及重置时长改进基础上，新增与监控协议分离的 BLE 固件升级协议、双 OTA 分区和首次启动回滚。macOS App 内置经过型号、版本、大小和 SHA-256 校验的正式固件；用户先通过 App 的“检查更新”完成 macOS 端升级，重启后的新 App 再通过已绑定加密 BLE 链路更新硬件。两个独立 ESP-IDF 目录已生成逐字节一致的 630,560 字节正式镜像；实物已在保留 NVS 和既有绑定的前提下完成一次性 USB 初始化、GATT 缓存迁移、`0.6.9 → 0.7.0` 真实 BLE 传输、设备校验、重启回连、OTA 0 Flash 回读和 `VALID` 状态确认。硬件屏继续定位为低频快照，不传输实时并发、活动任务、运行或等待数；普通页面和升级页面都已删除页码、按键教程、重复链路状态等冗余注解。

- `HARDWARE_MONITOR_DESIGN_ZH.md`：整体方案、硬件决定和实施进度；
- `firmware/`：正式 ESP-IDF 固件；
- 设备专属 Flash 备份、构建缓存和临时日志放入 `tmp/yyyy.mm.dd/`，不得提交。

本机 ESP32 工具和依赖只使用 MacPorts。固件使用 ESP-IDF 5.5.2；屏幕只在切页、链路状态或实际显示值变化时刷新，相同数据不会重复重绘。独立离线检查关闭时，设备仍会按当前页同步周期延迟判定 Mac 离线。绑定使用 LE Secure Connections Just Works，有加密但没有 MITM 认证；实体按键和限时窗口是首次授权边界。下一阶段是电池功耗、RTC 定时休眠和外壳验证。

ST7305 显示适配层基于 Waveshare 的 Apache-2.0 示例修改；原始版权、许可证副本和修改声明保存在 `firmware/components/u8g2_st7305/`。
